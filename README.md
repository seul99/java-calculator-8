# java-calculator-precourse

## 구현할 기능 목록
- [ ] 빈 문자열 또는 null 입력 시 0을 반환한다.
- [ ] 쉼표(,)나 콜론(:)을 구분자로 사용하는 문자열을 입력하면 구분자를 기준으로 분리한 숫자의 합을 반환한다.
- [ ] 커스텀 구분자 지정할 수 있다.
- [ ] 입력 값 중 음수가 포함된 경우 `IllegalArgumentException` 을 발생시키고 애플리케이션을 종료한다.
- [ ] 입력 값이 숫자가 아닌 경우 `IllegalArgumentException` 을 발생시키고 애플리케이션을 종료한다.
